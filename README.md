# Our Little Story — دليل التعديل

## التشغيل
افتح ملف `index.html` بأي متصفح. مفيش تثبيت ولا إنترنت مطلوب
(الإنترنت بس عشان الخطوط من Google Fonts).

## الملفات
- `index.html`  : هيكل الصفحة (مش محتاج تعدله).
- `style.css`   : الشكل والأنيميشن.
- `script.js`   : الحركة والمنطق (مش محتاج تعدله).
- `config.js`   : **كل حاجة بتعدلها موجودة هنا.**

## فين أغيّر إيه؟ (كله في config.js)

| عايز تغيّر | ابحث عن |
|---|---|
| اسمها | `name` (en / ar) |
| توقيعك في الآخر | `signature` |
| رقم واتساب | `whatsapp` (بالكود الدولي بدون + ، مثلاً 201012345678) |
| الرسالة اللي تتبعت أول ما تفتح واتساب | `whatsappText` |
| تاريخ عيد ميلادها (العد التنازلي) | `birthday` بصيغة `"2027-03-15T00:00:00"` |
| مكان الخروجة (اليوم والساعة بتختارهم هي) | `dateNight` |
| الألوان | `theme` |
| رسايل زرار NO (وعددها = عدد المحاولات الإجبارية قبل ما YES يتفتح) | `noMessages` |
| صورة أو رسالة المفاجأة | `surpriseImage` و `t.en.surMsg` / `t.ar.surMsg` |
| كل النصوص (عربي وإنجليزي) | `t.en` و `t.ar` |

## إضافة الصور
1. حط الصور في `assets/photos/` (مثلاً `photo-04.jpg`).
2. في `config.js` ضيف سطر جديد جوه `memories` أو `timeline`:

```js
{ image: "assets/photos/photo-04.jpg", date: "2025-05-01",
  title: { en: "Sunset", ar: "الغروب" },
  text:  { en: "A quiet evening.", ar: "مساء هادي." } },
```
لو الصورة مش موجودة هيظهر مكانها قلب جميل ومش هيبوظ الموقع.

## إضافة حدث في التايم لاين
ضيف جوه `timeline`:

```js
{ date: "2025-06-10",
  title: { en: "Our Trip", ar: "رحلتنا" },
  text:  { en: "...", ar: "..." },
  image: "" },   // الصورة اختيارية
```

## إضافة سبب جديد في "ليه بحبك"
ضيف جوه `reasons`:

```js
{ en: "Your laugh.", ar: "ضحكتك." },
```

## الموسيقى
حط الأغنية في `assets/music/our-song.mp3`.
لو اسمها مختلف غيّر `music` في `config.js`. لو مش عايز موسيقى خليها `""`.
الأغنية مش بتشتغل لوحدها؛ بتضغط على زرار الموسيقى الصغير.

## ملاحظات
- كل نص لازم يتكتب بالنسختين `en` و `ar`.
- بعد أي تعديل اعمل Refresh للصفحة.
- لو الموسيقى أو الصور مش بتظهر، اتأكد إن اسم الملف مطابق تمامًا (حروف كبيرة وصغيرة).
- لنشر الموقع كرابط: ارفع الفولدر كله على Netlify Drop أو GitHub Pages.

## الميزات الجديدة (تحديث)
- **مؤشر الفصول (01/05):** بيظهر في الزاوية أثناء السكرول فوق خمس أقسام رئيسية (حكايتنا، ليه بحبك، ذكرياتنا، الرسائل، القسم الأخير). العناوين في `chapters` جوه `t.en`/`t.ar`.
- **عداد "بقالنا بنصنع ذكريات":** بيحسب تلقائيًا من تاريخ أول حدث في `timeline` (نفس البيانات، مفيش تاريخ جديد تضيفه).
- **قسم "حاجات اتعلمتها عنك" (مرح):** كروت بتتقلب زي "ليه بحبك"، النصوص في `funny` جوه `config.js`.
- **النبض التفاعلي (Heartbeat):** زرار قلب بتدوس عليه والرقم بيزيد، وبعد كام دوسة بتظهر رسالة مرحة.
- **لعبة "اختاري واحدة":** أزواج اختيارات في `choices` جوه `config.js`، وبعد ما تختار كل الأزواج تظهر رسالة ختامية.
- **"قبل ما تمشي..." في آخر الصفحة:** سؤال "هل كنتي هتختاري القصة دي تاني؟" بزرارين، وبعد الاختيار تظهر توهج ورسالة أخيرة قبل توقيع Eng Aly.
- **Easter egg إضافي:** دبل-كليك على أول صورة في المعرض يفتح رسالة سرية تانية، غير نجمة السقف الموجودة.
- **لمسة أنيميشن عامة:** تأثير "ripple" خفيف عند الضغط على أي زرار رئيسي، وارتفاع بسيط لبعض الكروت عند الماوس (ديسكتوب فقط).

كل الميزات دي بتحترم `prefers-reduced-motion` وشغالة باللغتين والاتجاهين، واتفحصت بالكامل من غير أخطاء.

## الخروجة (الكالندر)
بعد ما تختار يوم الكالندر بيختفي وتظهر شاشة اختيار الساعة (AM/PM)، وبعد ما تأكد بيظهر "اتفقنا! ❤️" وزرار "ابعتي الموعد على واتساب" بيفتح رسالة جاهزة فيها اليوم لنفس رقم `whatsapp` اللي في `config.js` (نفس رقم زرار واتساب الأخير). نص الرسالة في `dateMsg`.

## الحرف على القمر / الرسائل / مقياس الحب
- الحرف اللي على القمر: `moonLetter` في `config.js` (بجانبه قلب أحمر).
- الرسائل المقفولة: `letters` (كل رسالة ليها عنوان `label` ونص `text` بالعربي والإنجليزي، وضيف أو احذف براحتك).
- مقياس الحب: جمل الأنيميشن في `t.en.meterSeq` و `t.ar.meterSeq`، والجمل النهائية في `mx` و `minf` و `mnote` و `mcnt`.
